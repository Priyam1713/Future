This is a recommendation, not a certified implementation.

Keep mathematical correctness separate from empirical forecasting skill. Likelihood ratios are assumptions unless independently estimated. Repeated or dependent evidence cannot be multiplied as independent support. For prior 1/5 and likelihood ratio 3, the exact posterior is 3/7. Impossible evidence requires an undefined/rejection result.

Name scoring conventions explicitly. Binary Brier loss is (p−y)^2 on 0–1; the two-category sum is twice this value on 0–2. The tournament paper uses daily/question averaging, which differs from a single selected cutoff forecast. Log loss needs explicit infinite-loss endpoint handling. Calibration bins are descriptive, and multiple updates or participants on the same question do not create independent events.
