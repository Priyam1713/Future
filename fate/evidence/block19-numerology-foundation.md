# Block 19 · The Personal Code

The FATE consumer layer reads the existing Decoz result without changing the native engine, API, export or Workbench. The earlier Codex snapshot holds only Life Path, Expression and Personal Year. A new schema-2 chapter adds the exact ordered passages, their edition and allow-listed rules while retaining that snapshot shape. Old chapters reopen with their original source edition.

The frozen edition registry is `fate/web/src/numerology/readingEdition.ts`. It holds original concise symbolic summaries and numbered locators. The room distributes no source page, source imagery or forecast text. Chaldean, Lo Shu, gematria, alternate boundary conventions and automatic transliteration remain separate. Current-name overlays use the verified calculation only. [Decoz current-name discussion, Part V](https://www.worldnumerology.com/pdf-sample-reports/ULT-sample-for-download.pdf)

The live reading shows the selected calendar date and uses the native endpoint for date changes. Changing the date replaces the live result and its commentary consent. Optional Gemini commentary is offered for the birth-name Expression and Personal Year themes. Saved chapters keep calculated values and passages, including the original day of the month in the Birthday passage. Values can reveal inferred birth information. Names, full dates, letters, Y classifications, receipts and commentary stay out of the Codex. Saving remains local and explicit. JSON export is available. File import remains deferred.

Run `node scripts/capture-personal-code.mjs` from `fate/web` with the built app running to reproduce the synthetic reading, persistent browser restart, accessibility and 200% browser zoom checks.
