# FATE — The Turning Sky / Art Pack 01

Original cinematic observatory art for the forthcoming *time-based Western transit* experience.

## Integration
- Source file: `turning-sky-observatory-source.png`. Keep unchanged in the creative-source collection.
- Desktop responsive assets: `turning-sky-observatory-1536.webp`, `-960.webp`, `-640.webp`.
- Vertical mobile crop: `turning-sky-observatory-mobile-720.webp`; use a gradient overlay for readable HTML text.
- Suggested application: lazy-loaded environment backdrop for a time-dial / dated-transit timeline; create separate responsive CSS crops.
- All actual zodiac/planet positions, chart lines, aspect geometries and date labels MUST be rendered live from existing verified native Python results, NOT from this painting. The armillary sphere is an atmospheric prop, not a chart.
- Add subtle parallax/low-opacity fog/light caustics only when visible. Keep user input and event text accessible, with reduced-motion and no-WebGL fallbacks.
- The provided artwork has no baked interface text. The app must add all controls and readings as HTML/SVG.

## Rights and reproducibility
`manifest.json` provides file hashes and the generation prompt. The images are original generated creative output (no third-party stock or fonts included). The source image and derivatives are separate, versioned assets.
