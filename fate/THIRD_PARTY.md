# FATE asset and dependency provenance

- **FATE Asset Pack 01:** supplied by the project owner from `Downloads/FATE-asset-pack-01.zip`. Its included README declares original project-specific procedural artwork, no third-party stock images, and original synthesized audio. Independent orb / atmosphere / orrery / sigil layers and the three audio files are used. `preview.jpg` is retained as a reference asset and is never used as application UI. The ZIP digest and individual asset hashes are recorded in `assets.json`; the original README is preserved verbatim. This is provenance from the supplied pack, not a claim of an independent copyright audit of its creation.
- **Block 01 celestial card edition (superseded):** the original code-authored geometric emblems, landscapes and suit pips remain available in Git history. Block 01.5 replaces them in the runtime with the complete illustrated Archive Edition below; `CardArt.tsx` preserves the public component interface as a registry-backed wrapper. No contemporary copyrighted Tarot deck or reference-site screenshot is substituted.
- **Block 01.5 Archive Edition (supersedes the original runtime emblems):** a complete 78-card set of historical Pam-A illustrations by Pamela Colman Smith, dated 1910 in Commons metadata, from [the TaionWC collection](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)). Each file's public-domain designation, artist, date, restrictions, source page, revision / original SHA1 and delivery SHA256 were checked and retained in `artwork-sources.json`. No contemporary recoloring or mixed set is substituted. Runtime WebP files are full-scan delivery derivatives only. Metadata fields are from Commons' CC0 structured records; the collection is not a new engine source or a change to the frozen Waite text profile.
- **Block 01.5 generated artwork:** the original FATE observatory back and nebula texture were made with the built-in image-generation tool. Original PNGs, exact prompts, conversion recipes and derivative locations are retained under `design/`. The static orb poster was extracted from the actual Pixi renderer and contains no React UI. These are project-created assets, not claims of historical illustration or external stock licenses. The prior SVG emblems remain in Git history and are no longer mixed into live readings.
- **Historical Tarot wording:** unchanged `knowledge/tarot_waite_v1.json`, profile `waite-1922-text-v1`; source IDs, locators, page links and rights notes travel with the native report. Its original public-domain/source limitations remain intact. No modern deck booklet is redistributed.
- **Cormorant Garamond / Inter:** self-hosted Latin WOFF2 files from Google's font service. SIL Open Font License texts and the exact source URLs are included in `web/public/fonts/`. No font service is contacted at runtime. `fetch_fonts.py` documents the one-time source acquisition; it is not a runtime or build dependency.
- **Runtime npm packages:** pinned in `web/package-lock.json`. React, React DOM, PixiJS, Lucide and their transitive runtime package license texts are collected in `THIRD_PARTY_LICENSES.txt`. Development tools remain separate in the lockfile. No new Python runtime library beyond the existing FastAPI / Uvicorn foundation is introduced.
- The published `@pixi/colord` package declares MIT but omits a standalone license file. Its declared upstream's [LICENSE.md](https://github.com/omgovich/colord/blob/master/LICENSE.md) is retained with its source URL in the collected notices.

The original vision documents' web references were treated as art direction, not as reusable image assets.
# FATE Block 02 original artwork

The celestial brass dial and observatory hall were created for this project with the built-in imagegen tool. Exact prompts, methods and source/delivery paths are recorded in `fate/design/block02-artwork.json`; source PNGs are retained in `fate/design/sources/`. Delivery conversion resizes/encodes only. The complete historical Tarot edition and its per-file rights records are unchanged.
# FATE Block 03 original artwork and source reference

The celestial Codex cover is original project artwork generated with the built-in imagegen tool; exact prompt, source PNG and responsive delivery paths are in `fate/design/block03-artwork.json`. Runtime title, binding, pages, light and interactions are independent programmatic layers. The frozen Codex reference reuses the already recorded Waite text/catalog and short original Numerology source summaries, without a new copyrighted corpus or interpretation engine. Existing Tarot illustrations, source/rights metadata and font licenses are unchanged.

Block 04 uses the owner-supplied original OpenAI-generated Western Observatory environment package. Unmodified source, prompt, manifest and delivery hashes are retained in `design/block04-artwork.json` and `design/block04-package-README.md`. No astronomical geometry or UI text is baked into the environment. The native JPL kernel is separately obtained under the existing project policy; it is not added to Git.

GeoNames cities15000 data, https://www.geonames.org/ and https://download.geonames.org/export/dump/cities15000.zip, is licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). FATE's server-only `data/places-v1.json` is an adapted field projection: geoname ID, name, ASCII name, country, admin1, coordinates, IANA zone and population; sorted by population, without alternate-name/full-record fields. Acquisition/projection hashes and count are recorded in `data/places-provenance.json`. Data are supplied as-is; city reference points and current labels are not exact hospitals or historical boundary guarantees. UI attribution links to GeoNames. No remote geocoder is used.

Rollup's official `@rollup/wasm-node` 4.68.7 is pinned as the FATE build backend under Rollup's MIT license, replacing its native optional parser for this Windows host. Upstream notices remain in the installed dependency; no upstream code or system policy was modified.

Block 05 uses the owner-supplied original OpenAI-generated Turning Sky Art 01 package. Source image, original creative prompt, archive hash and all delivery hashes are retained in design/block05-artwork.json and block05-package-README.md. Environmental armillary artwork is not a factual star map; native data geometry and all interface text are independent. Transit source text is the existing rights-scoped project research catalog, frozen by identity/version for Codex reuse; no new textbook ingestion.

Block 09 uses [Natural Earth 1:110m land](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) under its [public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/). The reviewed source tag, digest, projection, ImageGen prompts, and responsive artwork hashes are recorded in `design/block09-artwork.json`. The basemap is local and the angular overlays come from the native engine.
